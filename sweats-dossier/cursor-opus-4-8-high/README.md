# sweats-dossier — cursor-opus-4-8-high

**The Soft Stack** — a personal-shopper lookbook making the case to Jay Hack for which high-quality sweats to buy, calibrated to the James Perse / Fear of God bar.

## How to view

Open `index.html` directly in any desktop browser — no build, no server, no `npm install`.

```
open index.html
```

All imagery loads from the local `images/` folder, so the report renders fully offline. Product links open the live brand pages.

A fully self-contained single file (all images embedded as base64) is mirrored for the results site at
[`../../docs/artifacts/sweats-dossier/cursor-opus-4-8-high.html`](../../docs/artifacts/sweats-dossier/cursor-opus-4-8-high.html)
(and `public/artifacts/sweats-dossier/cursor-opus-4-8-high.html`).

## What's inside

- **The Man** — a dossier on Jay (Head of AI @ ClickUp; founder of Codegen and the Mira AI beauty-personalization company; ex-Palantir; Stanford CS/AI; `@mathemagic1an`) and how each fact maps onto the picks.
- **The Thesis** — one opinionated read: build *one tonal rotation*, relaxed-but-clean, earned in the hand not the logo. Fit profile, palette, and the three occasions it has to cover.
- **Compare** — two hand-built SVG charts (price × fabric weight, and a casual↔luxe / slim↔relaxed style map) plus a spec table, so the trade-offs are legible at a glance.
- **The Picks** — 7 specific products across 6 houses, each with brand, name, price, link, a fabric/construction note, a product image, and a reason tied to something the report actually learned about Jay.
- **Run It Back** — a 3-piece minimum viable rotation to start, designed to make him come back for round two.
