# codex-gpt-5-4-mini

## What was built

One self-contained HTML page for the `fishtank-water-sim` eval.

- black background
- open-top glass cube tank
- visible water volume and rippled surface inside the tank
- overhead pour stream that starts above the tank and fills it
- persistent slosh after the pour finishes
- mouse movement that disturbs the water
- custom drag-orbit camera and wheel zoom
- reset button that replays the pour

## How to run

Open [`index.html`](./index.html) directly in a desktop browser with network access for the Three.js CDN, or serve the folder as static files.

## Required environment variables

None.
